Next Step B

Two research tools — one dataset

Student-Facing Tool

Course Recommender

A student selects their target role — AI Engineer, Data Scientist, ML Engineer — and the tool returns ranked course recommendations based on how well each course covers that role's keyword demand.

  • Role selector: 7 data science roles
  • Course ranking by demand alignment score
  • Keyword gap explanation per course
  • Specialization pathway suggestions
Professor-Facing Tool

Curriculum Gap Dashboard

Professors and program directors see which market keywords are underrepresented across the MSDS curriculum, and which courses are best positioned to close each gap.

  • Keyword heatmap across all courses
  • Gap ranking: most-demanded, least-covered
  • Per-course coverage score over time
  • Role-by-role demand breakdown
